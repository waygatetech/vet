Rulings (2026-10-08, Brian): findings.Report + acceptance_ref; new reviewer_command; base main + merge-base + untracked. New concept, contracts, and moving Run into findings approved.

- `internal/findings`: move critique's `Run`/`parse` here as `findings.Run(ctx, argv, prompt)` (exec agent, prompt on stdin, extract JSON, strict decode, fail closed). Add `AcceptanceRef` (`acceptance_ref,omitempty`). `critique` calls it; its tests move with it.
- `internal/config`: `ReviewerCommand []string` (`reviewer_command`), default `[claude, -p]`.
- `internal/review`:
  - `Prompt(plan, diff string, context []critique.File) string`: reviewer instructions (check diff against plan + acceptance criteria, flag diffs contradicting context rulings without a supersedes entry; reply with findings JSON only).
  - `Diff(ctx, base) (string, error)`: `git merge-base <base> HEAD`, `git diff <mb>`, plus `git diff --no-index /dev/null <f>` for each `git ls-files --others --exclude-standard`.
- `main.go`: `review` subcommand. Reads plan + contexts (exit 2 on read error), builds diff (exit 2 on git error), runs reviewer (exit 3 on failure/malformed). Prints `[severity] check file:line message` lines, or the JSON report with `--json`. Exit 1 if `Blocking()`.
- Tests: review.Prompt contents; Diff in a temp git repo (committed + untracked file); main_test review exit codes (pass, blocking, malformed → 3, missing plan → 2, --json output).
- concepts.yaml: register `review`. README: usage + config key.
