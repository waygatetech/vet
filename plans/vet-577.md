Rulings (2026-10-08, Brian): remove reviewer_command; --tier flag; struct triggers, OR, missing when = always. All recommendations accepted.

Config (`internal/config`): `Reviewers []Reviewer` where `Reviewer{Name, Command []string, When *Trigger}` and `Trigger{ContractsChanged bool, MinTier int, Paths []string}`. Default when empty: one reviewer `claude` running `claude -p`. Load rejects (exit 2) empty or duplicate names and empty commands.

Review (`internal/review`):
- `Triggered(r, contractsChanged bool, tier int, files []string) bool`.
- `Files(diff)` gets changed paths from the `diff --git a/X b/Y` headers.
- A small glob matcher where `**` matches zero or more path segments and every other segment uses `path.Match`. The stdlib has no `**`, and adding a dependency isn't worth it here.
- `critique.frontmatter` gets exported so review can read `contracts_changed` from the plan.

Findings: `Finding.Reviewer string json:"reviewer,omitempty"`. vet overwrites it with the configured name after parsing.

main.go `vet review`:
- Add a `--tier` flag. Select the triggered reviewers. If none trigger, that's exit 2 so the gate fails closed.
- Run the triggered reviewers concurrently with the same prompt (WaitGroup plus a results slice) and merge their findings.
- If any agent fails, exit 3. If any finding is blocking, exit 1.
- Text output includes the reviewer name.

Tests: table-driven tests for config validation, trigger matching, the glob matcher, and Files(); a main_test case with two reviewers where one blocks.

README: document `reviewers`/`when` and `--tier`.
