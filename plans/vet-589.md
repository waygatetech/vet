Rulings (2026-10-08, Brian): yaml.v3 strict; log_level only; Report wrapper. All recommendations accepted.

Layout: `main.go` (package main) at the repo root, so `go install github.com/waygatetech/vet@latest` works.

- `main.go`: Cobra root command `vet`, a persistent `--config` flag (default `.vet.yaml`), and slog to stderr at the level from the config. `version`/`commit`/`date` vars are set via ldflags and exposed through Cobra's `Version`. An `exitError{code}` type plus `run() int` map errors to exit codes: usage errors and config errors return 2. Codes 1 and 3 are constants for critique/review to use.
- `internal/config`: `Load(path string, explicit bool) (Config, error)`. If the default file is missing, return defaults. If an explicitly passed file is missing, or the YAML is invalid or has unknown keys, return an error (exit 2).
- `internal/findings`: `Severity`, `Finding`, `Report`, `Report.Blocking()`, and severity validation on unmarshal.
- `.goreleaser.yaml`: builds a single binary and sets ldflags for `main.version`/`commit`/`date`.
- `concepts.yaml`: registers cli, config and findings.
- `README.md`: a short usage section, the exit-code table, and a note that this is not `go vet`.

Tests: table-driven tests for the config load cases, findings JSON round-trip and invalid severity, and the exit-code mapping in main_test.go.
