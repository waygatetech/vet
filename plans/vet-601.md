Usage) with a table: field, type, read by, required. Fields from the yaml tags:

- `ticket` (string): `vet lock`, `vet lock --check`; required by both; must be a plain file name (no `/`, not `..`).
- `tests` ([]string globs, `**` spans dirs): `vet lock`, `vet lock --check`; optional (no tests = check passes).

- `contracts_changed` ([]string): `vet review` `contracts_changed` trigger; optional.

command errors on malformed frontmatter.
